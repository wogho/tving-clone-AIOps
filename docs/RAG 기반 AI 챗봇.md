# TVING 초개인화 RAG 기반 AI 콘텐츠 추천 챗봇

## 1. 개요 (Overview)

본 문서는 **TVING 클론 서비스**에 구현된 **Amazon Bedrock (Claude 3 Haiku) 기반 초개인화 RAG(Retrieval-Augmented Generation) 콘텐츠 추천 챗봇 시스템**의 아키텍처와 구현 명세를 기록합니다.

* **목적**: 사용자의 질문뿐만 아니라 **시청 이력(Watch History), 찜 목록(Wishlist), 실시간 라이브러리 메타데이터**를 RAG 컨텍스트로 결합하여 넷플릭스/티빙 수준의 맞춤형 큐레이션 제공
* **모델**: Amazon Bedrock `apac.anthropic.claude-3-haiku-20240307-v1:0` (서울 리전 `ap-northeast-2`)
* **연동 인터페이스**: 
  * 백엔드 API: FastAPI `POST /api/chat`
  * 사용자 UI: Streamlit 웹 애플리케이션 (`:8501`)

---

## 2. RAG 아키텍처 흐름도 (Architecture Flow)

```text
[사용자 질의 입력] (예: "주말에 가볍게 볼 만한 드라마 추천해줘")
        │
        ▼
[FastAPI 백엔드 (/api/chat)]
        │
        ├─▶ 1. [사용자 프로필 검색] PostgreSQL에서 사용자 시청 이력 & 찜 목록 조회
        │      (예: 시그널 85% 시청, 비밀의 숲 찜)
        │
        ├─▶ 2. [콘텐츠 라이브러리 검색] 전체 콘텐츠 메타데이터(장르, 카테고리, 줄거리) 로드
        │
        ▼
[Bedrock RAG Dynamic Prompt Assembly]
┌─────────────────────────────────────────────────────────────┐
│ • 역할 정의: TVING 초개인화 AI 콘텐츠 큐레이터               │
│ • Context 1: 사용자 시청 이력 및 취향 데이터                │
│ • Context 2: TVING 전체 콘텐츠 카탈로그 (줄거리 포함)        │
│ • Question: 사용자 질문                                     │
│ • Guideline: 이전 시청 취향과 연결하여 추천 사유 명시       │
└──────────────────────────────┬──────────────────────────────┘
                               │ (Bedrock Converse API 호출)
                               ▼
[Amazon Bedrock (Claude 3 Haiku)]
                               │ (자연어 큐레이션 생성)
                               ▼
[초개인화 추천 결과 반환] ➔ Streamlit UI & 웹 프론트엔드 표출
```

## 3. 핵심 구현 세부 사항

### 3.1 백엔드 API 명세 (`backend/routers/chat.py`)

* **Endpoint**: `POST /api/chat`
* **Request Body**:
  ```json
  {
    "message": "스릴러 장르 추천해줘",
    "user_id": 1
  }
  ```
* **Response Body**:
  ```json
  {
    "reply": "TVING AI 큐레이터입니다! 고객님께서 최근 '시그널'과 '비밀의 숲'을 재미있게 시청하셨더군요. 두 작품처럼 치밀한 두뇌 싸움과 긴장감을 선호하시는 고객님께 '보이스'를 추천드립니다...",
    "personalized": true,
    "context_used": {
      "watch_history": ["시그널 (스릴러, 85% 시청)", "비밀의 숲 (추리/스릴러, 100% 시청)"],
      "wishlist": ["괴물 (스릴러)"]
    }
  }
  ```

---

### 3.2 Streamlit 챗봇 UI (`streamlit/app.py`)

* **접속 주소**: `http://localhost:8501`
* **주요 기능**:
  * **사이드바 프로필 선택기**:
    * `일반 사용자 (비로그인)`: 전체 카탈로그 기반 일반 추천
    * `User 1 (스릴러/드라마 애청자)`: 시그널, 비밀의 숲 기반 맞춤 추천
    * `User 2 (예능/로맨스 애청자)`: 환승연애, 지구오락실 기반 맞춤 추천
  * **RAG 반영 뱃지**: 시청 데이터가 반영되었을 때 상단에 `✨ 시청 이력 RAG 반영됨` 캡션 표출
  * **대화 세션 유지 및 초기화 버튼** 지원

## 4. 라이브 데모 시연 시나리오

1. **Step 1 (비로그인 일반 추천)**:
   * 사이드바에서 `일반 사용자 (비로그인)` 선택
   * 질문: *"요즘 볼 만한 예능 추천해줘"*
   * 결과: TVING 라이브러리의 인기 예능 2~3편 기본 소개
2. **Step 2 (시청 이력 연동 맞춤 추천 - 킬링 포인트 ⭐)**:
   * 사이드바에서 `User 1 (스릴러 애청자)` 선택
   * 질문: *"오늘 밤에 볼 거 하나만 골라줘"*
   * 결과: *"고객님께서 시청하신 '시그널'의 수사 스릴러 감성을 이어받은 '...'을 추천합니다!"* 와 같이 시청 이력을 직접 언급하며 추천

## 5. 차별점 및 기술적 완성도

1. **단순 프롬프트가 아닌 DB 데이터 기반 RAG**: 하드코딩된 답변이 아니라 실제 PostgreSQL 데이터베이스의 콘텐츠 테이블과 시청 기록 테이블을 실시간 결합
2. **비용 효율적인 Bedrock 모델 선택**: 속도가 빠르고 비용이 저렴한 `Claude 3 Haiku` 모델을 채택하여 1~2초 내의 초고속 실시간 응답 보장
3. **AIOps 시스템과의 완벽한 시너지**: 평소에는 정상 콘텐츠 추천 챗봇으로 동작하다가, 비정상 부하/인젝션 시도 시 AIOps가 실시간 감지하여 방어하는 이중 구조 완성
